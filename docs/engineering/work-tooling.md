# 协调工具的实现边界

操作判断与生命周期只在[协调协议](../coordination.md)维护，字段与命令只在[记录索引](../work-records.md)维护。本页用于修改工具时核对实现保证，不追加每轮实施经过。

## 职责与记录

任务协调位于 `scripts/harness/work/`，与工程护栏同属 `scripts/harness/`；Profile、启动与产物 smoke 位于 `scripts/service/`。两者按职责检查依赖，运行时不得导入。公共检查验证工具与公开资料，不读取成员的私人记录；本地 `work check` 核对本人的任务。无需个人 Skills、后台服务或第二套进度台账。

ensure 由文档身份和稳定任务键定位记录，section 用 Markdown AST 核对真实唯一标题；section 更正保留 source/key/ID。update 校验 revision，阶段转换要求当前 nextAction，自动动作刷新保守后继；nextAction 不进入内容候选，其业务语义由审阅判断。候选绑定内容与契约，成员和工作区标记归属。旧记录读取不升级或重绑证据。`work exec` 检查 C1 后启动命令，不回滚失败修改，也不是宿主写入拦截或进程沙箱。

源码盘点区分生产、测试、开发脚本、配置、公共资料与生成/运行目录，未知文件拒绝。QUALITY-01 按真实源码 scope 保守触发现有三维审查，包含计划新增路径与删除最后一个源码；只读 inputs 不触发。NORMS-01 用同一个 v2 norms-review 对账需求／方案、现行规范与相关接受；CLI 校验格式、绑定与结论一致性，不能证明人工观察真实。维护不因需要审查而创建开发 result。

## 分层读取与完整性

status 仅生成分页目录；context、ensure、update 的返回与 check 使用同一 assess 核对完整现场，输出再投影为有界视图。实际阻塞和视图省略分别表达，省略不改变核验结论；这些核对入口明确显示已声明或未声明的 result，不根据缺项判定任务类型。操作成功、记录阶段和核验结论分别表达；使用条件统一见[核对与同步](../work-records.md#核对与同步)，没有另存的已读状态。

guide 默认返回当前动作的章节入口，显式选择后按 Markdown AST 的真实标题边界读取；代码围栏中的示例标题不算导航。read 展开选中的记录、核验或已登记证据；read-result 按 PRD/key 读取公共成果，changes 按 PRD 分页摘要或展开所选正文，均无需作者记录。分页受输出预算和内容摘要约束，续页遇到内容变化明确拒绝。完整性检查在进程内读取相关字节，与送入模型的正文分开；显式子命令和宿主直接读文件不受这套展示边界强制限制。

各 PRD 的 `documents.json` 是其需求资料的唯一身份注册，类别为 prd/design/proposal/change；中央配置不保存任务条目。共享 resolver 用于 ensure/update、capture、交付与文档检查，发现全部登记并核对跨登记唯一性、资料归属与合法路径；change 从规范形状的 identity 读取 ID，并要求当前路径 ID 一致，唯一标题、单一元数据块和父章节也须有效。父 PRD 目录迁移可保留原 identity 和必要别名。候选绑定固定公共规则、真实工程配置、实际声明的资料与相关登记文件；未读取的同 PRD 正文和合法无关 PRD 不成为隐式输入，显式广 scope 仍展开全部命中文件。活动资料通过静态任务入口的真实目录链接或显式正文链接可达，不能借历史正文取得发现资格。重复身份、未知页、私有/越界/符号链接和孤儿公开产物明确拒绝；JSON 仅精确分类登记和成果记录文件。

变更索引只从合法登记生成到所属 PRD 固定路径，字节相同不重写；无变更不生成。公共文档检查报告缺失、过期、空目录索引及父 PRD 链接问题，catalog 和执行现场捕获不把索引缺失或过期当成阻塞，以便实施命令修复；正文或归属错误仍阻断。单写入者、授权和 `work exec` 规则仍由操作协议约束，生成命令不是宿主沙箱。

## 每份 PRD 的公共包

可验收开发能力才设置 `plan.result={prd,key}`；维护在个人记录中核对和归档。公共 v5 包位于注册 PRD 当前目录的 `complete/`，稳定身份与物理路径分别核对，不从旧身份字符串拼接输出位置。目录规则见[资料归属](../index.md#增长与归属)。

`records.json` 顶层是 version、prd、results；每项包含 key、title、outcomes、locations（path/purpose）、verification、limitations、acceptance（candidate/statement/reference）。接受标识不附带可恢复代码或证据；完整 checkpoint 和必需原件仍在开发流程核验。`report.md` 仅导航成果与入口，并用原 v5 元数据绑定记录路径和内容哈希。read-result、receive 与公共检查直接沿注册 PRD 定位配对文件，核对身份、内容、单边缺件和孤儿，不消费全局成果索引或作者 `.work`。配对文件均不存在只表示当前无可发现成果，不能证明从未交付；按 key 读取、显式成果输入或已有报告引用仍须真实存在，历史删除事实须结合 Git 或既有接受来源核对。

只支持公共 v5，旧公共格式、历史恢复和逐证据 selector 已退出。`records.json#result=<key>` 绑定单项记录与所属登记；广泛 scope 展开兄弟成果，仅排除自身结果和所属生成导航，不复制开发清单到公共输出。新增无关 key 不改变指定成果的内容候选；inputStamp 仍观察物理文件及祖先目录，恢复后字节相同也可能使验证无效。独立 checkout/worktree 提供任务隔离；同一 checkout 的并发验收不在保证范围，不弱化恢复改写检测。

## 写入、恢复与保留

同任务 CLI 写操作在读取可变状态前独占命令标记，覆盖执行和保存；ensure/receive 得到 ID 后纳入。标记位于任务目录外，避免中断建档留下伪记录。读取和其他任务不受阻；不自动合并契约或证据。revision 另行拒绝过期请求，保存时比较字节后 rename 不构成对任意外部写入的原子 CAS。

WORK_CONFLICT 的回执在同一独占区记录，合法对账先保存、后清回执；交付 journal 优先恢复。失败事实不作为第二份进度，恢复操作统一见[核对与同步](../work-records.md#核对与同步)。

子进程执行采用可处理信号的等待；取消即使收到退出码 0 也不形成通过。执行组未确认结束或硬终止时保留占用，禁止按时间/PID自动窃取；操作与恢复步骤只在[命令占用与异常恢复](../work-records.md#命令占用与异常恢复)维护。任务标记不提供代码隔离或不同任务共同修改公共 PRD 包的事务，现有写入归属与隔离要求继续有效。

人工原件在登记和核验时共用声明解析：普通观察匹配候选、验收项和结论，质量／规范审查沿各自格式。原件读取检查独立普通文件，登记拒绝复用已变更的原件路径；这些检查不授予文件写入权，取证例外只在[验证与接受](../coordination.md#验证与接受)定义。

自动验收通过同一解析入口聚合直接执行、复用回执和基线与增量组合；context、check、交付草稿、complete 与交接报告读取当前结论。回执引用显式来源，不扫描私人任务目录，不缓存长期通过状态；每次核验来源链、哈希、后续问题及命令占用，失败、缺失或未结束撤回就绪。任务候选身份与检查文件快照分别绑定。声明、环境、旧记录接入及失败恢复统一见[增量验证与同输入复用](../work-records.md#增量验证与同输入复用)。机械校验不证明语义覆盖，也不发现声明遗漏的读取输入或自动探测远端状态。

prepare 校验当前候选全部必需原件，只生成私有 v5 草稿；草稿保存成果说明与原件元数据引用，不复制公开附件。complete 再核对原件、草稿和针对候选的真实接受，仅写所属 PRD 的 records/report 并保留兄弟成果。不同 PRD 没有共享公共交付写入；同 PRD 仍须单写入者。同 key 新候选需重新验证与接受，本阶段不要求旧结果先提交或保留恢复包。

新交付 journal 为 v2，保存请求与目标 before/after 字节，用于本次写入的中断重放和冲突检测，不是长期公共证据。逐文件原子替换不是跨文件事务；未完成新操作阻止其他记录写入，旧请求不得覆盖后续合法更新。旧 v1 或已完成且含全局索引目标的 v2 journal 作为历史保留，永不重放，只有显式新 prepare 可替换。未完成且含旧索引目标的 journal 在新工具中明确拒绝，须在独立 checkout 使用原工具版本核对原请求和输出，不能删除 journal 或让它覆写静态入口。旧个人状态继续可查看，旧草稿不能自动成为新候选通过，不批量迁移个人文件。

公共 receive 仅创建目标、成果引用和入口提示，不能比较历史文件或复原原件；授权、范围、验收项、checkpoint 和通过证据均需重建。个人精确代码 handoff 仍要求文件匹配，且不继承授权或通过。

`.work` 原件用于开发核验，archive 不删除文件。临时 fixture 可重建，不复制整仓作为长期成果。公开摘要、人工接受字段和脚本完整性检查都不能证明观察语义真实。
