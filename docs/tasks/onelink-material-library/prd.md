# 万联真人与 AIGC 素材库 PRD

状态：原 W6 的独立需求规划，尚未启动或接受。素材管理可先行，认证素材生成联动依赖对应可消费的视频能力；缺真实回调环境不伪称认证已验。返回[任务资料与成果](../index.md)。

## 1. 结果与范围

覆盖旧 WL-10：真人认证会话、素材组/素材增删改查、有界列表/状态同步、AIGC 素材验证、本地 ID → `asset://` 解析，并联调对应视频操作。组归属先以 owner 成立，未来项目模块只提供业务关联、消费同一服务，不复制供应商客户端。非目标为绕过认证、旧版全部项目/主体业务、正式 UI 和 Agent 工具。

协议调查来源为旧仓库 `backend/app/services/live_material_runtime.py` 的 `/volc/openapi?Action=...`，仅作迁移依据。素材线路是否绑定、认证和操作权限须独立验证，`/models` 成功不证明素材可用，也不受旧 92 个模型数量限制。

## 2. 直接依赖与 C0 缺口

本人配置和凭据身份直接沿[供应商规范](../../providers.md)，必要基线为已接受 `onelink-user-provider-catalog`（[成果入口](../onelink-integration/complete/report.md)）。资产、外部资源归属及 unknown/恢复直接引用[共享候选设计](../onelink-image-generation/design.md)。素材元数据 CRUD/同步可在 W1 后先行；涉及受管上传/引用时核对基础实际接口与代码，生成联动再消费[视频需求](../onelink-video-generation/prd.md)中已可消费的对应接口、精确模式与固定代码候选，核验实际就绪和接受状态；不把 W4 先获人类接受或整份视频/图片完成设为开发联调门禁。

C0 按所选切片核对实施/费用授权（O1）、外部资源和凭据保留/撤销（O2），O6 收口测试素材授权、万联线路绑定、公网回调 URL/验证、受限返回路径、外部资源保留删除及本地引用政策；涉及文件时核对 O4 资产上限和可达方式。缺公网回调只阻塞实际认证流程，不阻塞 CRUD 与协议替身验证；替身回调不能支持完整 W6 接受。

## 3. 独有身份与副作用

素材组和素材保存 owner、providerConfigId、上游 ID/来源；换 Key 或同步不能错误认领其他账号资源。真人认证回调绑定单次会话、到期和防重放验证，不接受客户端自报完成；收到回调后向上游复核，再允许 Active 素材生成。线路未绑定返回可操作的脱敏错误。

删除本地资产、删除上游素材和撤销认证是不同副作用，分别授权和表达；已有任务引用不得悬空。旧版按项目创建 AIGC 组的便利流程改由 owner 所属组承接，不因此新建项目 CRUD 或扩大素材授权。

## 4. C1 实施顺序

沿[统一生命周期](../../coordination.md#当前任务的生命周期)，先建立组/素材 owner 与供应商身份，实现有界同步和 CRUD；再提供认证会话、防重放回调/上游复核及状态转换，补 AIGC 验证。最后收口 Active 校验、本地引用解析并接对应视频服务。管理能力可独立切片交付，认证/生成联动保留真实缺口，不用替身结果转成完整接受。

相应素材/认证回调/删除规范、HTTP 与集成契约随切片在 verify 前采纳；同步中断、轮换和资源创建未知结果按原身份恢复，不通过新建外部资源绕过。

## 5. 验收与接受

共同原 A1/A2/A5/A7、批次原件及接受规则沿[共同验证约定](../onelink-image-generation/design.md#6-共同验证约定)。原 A9 另要求：

- 真人认证完整回路、AIGC 素材验证、组/素材 CRUD 与同步各有真实观察；至少一条受支持 `asset://` 视频生成真实闭环，精确模式与 W4 覆盖清单一致。
- 无线路绑定、未认证/拒绝/过期、伪造/重放回调、任意返回路径、跨用户/跨配置 ID、同步中断和删除引用冲突有负向证据。
- 上游状态复核和 Active 准入有效，换 Key 不自动认领，创建/删除未知保留原身份及副作用事实。

完整素材库接受需要管理、真实认证和生成联动目标均已验证或获明确处置并披露。对应高级视频模式须由 W4/W6 清单共同收口后才宣称完整，不把全部 W4 接受设为素材管理前置。
