状态：原 W3 的独立需求规划，业务尚未启动或接受。本次拆分只调整资料归属；W1/W2 旧接受不迁移。返回[任务资料与成果](../index.md)。

## 1. 结果与范围

覆盖 WL-04 的图片生成、参考图、编辑/扩图及异步差异，结果通过稳定 Asset ID 查询、鉴权下载和重启后再次读取。资产底座先由[私有资产与计算服务](../compute-service/prd.md)交付；W3 按图片场景核对和复用实际接受的资产能力，再补图片所需任务和资产行为，承接[共享候选设计](design.md)，不先建完整媒体平台。非目标为画布编辑器、项目/分镜、视频工作流、正式前端及 Agent 工具。

旧协议调查来自旧仓库 `backend/app/services/image_gen.py`，只作迁移参考：

| 协议族     | 必须保留的目标差异                                                              |
| ---------- | ------------------------------------------------------------------------------- |
| GPT        | `/v1/images/generations` 与 multipart edits，区分无参考图、参考图及 mask/编辑。 |
| Seedream   | `/volc/api/v3/images/generations`，按实际型号核对数量、尺寸、水印及参考图。     |

| Kling/Vidu | 图片提交/查询的异步身份、状态与取回。                                           |

从当前用户动态目录选精确代表，按实际协议和生成/参考图/编辑/多图/异步差异登记覆盖；单一型号不代表全部图片协议。旧 92 项不是可用白名单，目标无权限或无代表时保留相应 pending，不默删目标。

## 2. 直接依赖与 C0 缺口

复用[供应商规范](../../providers.md)中的本人凭据、稳定模型身份、动态资格和有来源声明，必要已接受基线为 `onelink-user-provider-catalog`（[原成果入口](../onelink-integration/complete/report.md)）；W2 文本完整接受不构成图片前置。身份、PG、传输与资源约束直接沿[共享候选设计的现行依赖](design.md#1-现行依赖与采用边界)。图片场景相关能力尚未按本 PRD 验证和接受；资产底座仍按本页首段核对实际接受范围，不能从目录成功推导可调用。

C0 收口本图片切片实施授权与非文本预算（O1）、O2 在途/外部资源凭据关系、O4 存储/容量/保留删除/上游可达输入、O5 精确协议操作清单；最小解决动作见[共同决定](design.md#5-仍须收口的共同决定)。参考图无公网可达方式时可做隔离协议验证，不能接受真实参考图闭环。规划交回不等于这些决定已解决，也不预建未来执行记录。

## 3. C1 实施顺序

沿[统一生命周期](../../coordination.md#当前任务的生命周期)，先核对资产底座已接受范围与图片场景差异，按需要补齐 owner 资产和上传/下载，再建立图片任务身份、提交/unknown 状态与逐输出结果。随后准备 reference/mask，按清单补各协议参数和响应；异步图片只扩展必要短步骤，不先引入通用队列。最后覆盖持久化、部分成功、下载重试与重启，后续视频/音频按实际能力复用。

每个切片同步实际采用的媒体/任务/存储规范、HTTP 与集成契约并接回权威导航，核对模块边界和资源关闭；图片独有参数留在图片能力，不放进共享设计。规划或基础切片通过不代表全部 WL-04 完成。

## 4. 验收与接受

共同证据、安全/恢复、批次费用和接受规则沿[共同验证约定](design.md#6-共同验证约定)，本能力覆盖原 A1/A2/A5/A6/A7，并额外逐项核验：

- 每协议族至少一个受支持生成场景；生成/参考图/编辑/多图/异步的不同分支分别真实验证，无参考图与有参考图构造不同，格式、数量、尺寸、水印满足该型号/操作限制。
- 跨用户资产、不可达输入、超限、伪类型和恶意重定向拒绝；URL 与 Base64 结果可解码，稳定资产重启后仍能下载。
- 注入“生成已成功 → 下载/元数据提交失败”，核对只恢复取回/落库、收费生成次数不增加、同 task/output 不重复 Asset；多图部分失败可见，保留可对账身份和有界临时文件清理。

确定性协议/隔离持久化与真实供应商结果分别报告。完整图片接受要求本页目标操作逐项有证据，未验项明确处置，所交切片的恢复、安全、完整检查及审查齐备并获真实接受；不得以基础切片或一次图片成功声明完整图片能力。
