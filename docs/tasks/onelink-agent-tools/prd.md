# 万联 Agent 生成工具 PRD

状态：原 W7 的条件性独立需求。只有用户另行明确要求 Agent 生成并采纳 O7 时启动；当前根与 Agent 工具全拒绝继续有效，文档拆分不授予工具或收费执行权限。返回[任务资料与成果](../index.md)。

## 1. 结果与非目标

官方 DSH loop 通过最小业务工具调用已接受的 Mio submit/query/cancel 等服务，返回 Mio task/asset 引用；复用同一身份、任务和副作用约束，不维护第二套 loop 或另一套生成服务。独立 HTTP 能力不隐含工具许可，也不要求先完成全部媒体 PRD。无关 Shell、文件、MCP 和动态插件管理继续禁止。

## 2. 触发、直接依赖与 C0

触发后按[统一生命周期](../../coordination.md#当前任务的生命周期)处理：O7 明确允许工具清单、每轮/每用户次数与费用约束、参数和资源授权、用户意图/确认时机、审阅边界及取消/再次执行语义；未确认的依赖动作继续拒绝。消费相应能力真正已接受的服务接口、固定代码及必要 result key，实施时从其所属成果核对，不把全部 W1–W6 作为一个总门禁，也不在本页预造未来 key。

可信用户和资源边界沿[认证底座](../../auth.md)，官方执行/装配和根/Agent 守卫组合直接沿[DSH 契约](../../integrations/dsh.md)。C0 必须查清实际组合及要替换的明确作用域策略，不能追加 allow 绕过拒绝；对应服务的输入、预算、unknown 和恢复契约以其实际现行规范为准。共享尚未采用的部分可参照[候选设计](../onelink-image-generation/design.md)，不能用它代替已接受服务契约。参数不接收 Key、owner 或任意 URL。

## 3. C1 实施要点

声明获准的最小工具，替换明确范围策略，从可信对话绑定派生主体后调用统一服务，记录可恢复任务身份。工具超时/再次调用按同一身份查询，不换 ID 新建收费任务。结果和日志只展示获准业务信息，当前对外历史/SSE 白名单不因工具内部数据自动扩大。

工具、DSH 与业务权限规范在该切片 verify 前与实际装配进入同一候选；拒绝路径保持业务函数未执行。只开放已确认的工具与作用域，不借本期扩大 Shell/文件/MCP 权限。

## 4. 验收与接受

原 A10 须经真实官方 loop 观察授权成功、未授权/跨用户/超限拒绝与提示注入负向路径，核对实际服务调用次数和返回 task/asset；工具调用夹具通过不能代替生产授权。对已提交运行重启、超时及再次调用不重复生成，取消和 unknown 沿该服务真实语义报告，拒绝路径函数不执行，无关工具仍不可执行。

确定性负向测试、正式 Profile/隔离存储、获授权真实业务和生产证据分别报告；真实收费批次仍受对应服务的授权/费用上限约束。完整 `pnpm check`、quality-review、norms-review 及适用独立审查齐备，且真实接受绑定本条件切片后，才可声明 Agent 可用所接受范围的万联工具；不能由单独媒体或文本接受推导。
