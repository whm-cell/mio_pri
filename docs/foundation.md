# 插件服务底座

## 当前范围与来源

本仓库是 TypeScript 后端 service，通过固定版本的 DeepSeek Harness（DSH）公开插件接口逐步积累后续业务所需的公共能力，不包含前端 UI，也不以旧 Python 行为替代需求。未来客户端通过公开服务接口消费能力；必要的调试前端可另建同级独立项目，不成为本服务构建或验收的硬依赖。

当前底座提供基础 HTTP 探针、受保护的能力查询，以及可配置的账号认证与持久会话；认证配置、迁移、模块职责和业务验证边界在[认证底座](auth.md)维护，数据库驱动、资源约束与隔离测试按 [PostgreSQL 使用契约](integrations/postgres.md)查询。外部行为按[API 领域规范](apis/index.md)查询。工程护栏、任务协调和正式插件产物检查随仓库提供。

项目、素材、对话服务、流式事件和生成业务尚未交付；SaaS 多租户和模型工具授权也不在当前能力内。近期候选范围见[后端对话服务 PRD](tasks/conversation-service/prd.md)，不以项目 CRUD 为前置；重连/取消、用户与对话归属及持久化仍须随对应需求实施验收，不能从账号会话或底座检查通过推导。

需求、安排和未采纳设计从[任务资料](tasks/index.md)进入；已接受范围从[成果索引](tasks/index.md)查找。历史接受只绑定当时受验候选，不代替当前源码、业务验收或生产证据。

## 结构决定

| 对象          | 决定       | 理由和边界                                                                                 |
| ------------- | ---------- | ------------------------------------------------------------------------------------------ |
| 官方 DSH      | reuse      | 使用已发布 `0.2.2-rc.1`；参考源码提交 `66491b05e3f05ad35bcdd4f6cd7ed26041d9e3db`，不改上游 |
| mio 插件包    | create     | 单个 ESM TS 包，使用 Profile/Bundle 装载；不维护第二套 Agent 循环                          |
| HTTP 处理     | create     | 基础探针/能力与认证各按领域规范处理；DSH 路由适配集中于插件入口                            |
| 账号认证      | create     | 已提供注册、登录与持久会话，具体运行契约见认证底座；登录状态不代替项目资源授权             |
| 项目/素材模块 | unresolved | 等具体业务需求后确定模块与数据归属，不创建空层                                             |
| 对话服务      | unresolved | 按独立 PRD 明确用户归属、接收/持久回执、事件、取消与恢复后接入 DSH；尚未实现               |
| 生成任务      | unresolved | 等具体业务需求明确外部副作用与恢复，不作为近期对话服务的前置                               |

Foundation 子域的导入方向是插件入口 → 基础 HTTP，基础 HTTP 与认证 HTTP → [共同响应原语](apis/index.md#运行时公共能力)，响应原语 → 运行时独立契约；响应原语不依赖认证或装配入口。认证配置与身份、装配、持久化和生命周期按[认证底座](auth.md)维护。只有插件入口可以导入 DSH/Cordis。测试可使用公开 DSH API 验证集成；运行时不得导入测试与开发脚本。跨包只使用发布的接口，不导入上游源码或其内部产物。

运行实例使用显式、独立的 `DSH_HOME`。当前 Profile 只装配 HTTP、工具注册和原生执行器等必要服务，没有模型适配器、文件工具、Shell、MCP 或动态插件管理工具；注册执行守卫拒绝全部工具。以后新增允许工具时必须同时定义输入、授权与副作用验收，不能仅增加工具名称。

## 验收与限制

- 核心：格式、类型、lint、护栏、测试、构建均成功；打包产物通过官方 `dsh --profile mio` 启动；受保护查询可用；正常停止后同一端口可再次绑定。
- 必要保障：缺少认证配置不可就绪；错误凭据、未知路径/方法与不允许的 Origin 被拒绝；真实工具函数在守卫下不执行；插件卸载撤销路由与守卫；结构/文档违规样例返回非零。
- 环境：Node 24（至少 24.9）、pnpm 固定版本、隔离的临时 DSH_HOME；没有生产数据、真实模型或收费供应商。源码导出可运行检查，Git 索引检查仅在 Git 仓库中有效。
- CI 文件只代表已接入配置；没有远端运行和分支保护证据时，不声称远端门禁已生效。

当前验收标准见 [验收入口](acceptance.md)，已接受开发成果通过 [PRD 成果索引](tasks/index.md) 定位。护栏维护与实验、个人执行状态、每轮结果及原件在各自 `.work` 维护，不在公共文档按日期追加。接口状态见 [API 约定](api.md)，日常命令见 [README](../README.md)。
