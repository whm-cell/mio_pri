# 万联异步视频与恢复 PRD

状态：原 W4 的独立需求规划，尚未启动或接受。W6 的认证素材联动单独验收，不因视频普通模式通过而算完成。返回[任务资料与成果](../index.md)。

## 1. 结果与范围

用户可显式提交目标视频操作、查询状态、请求受支持的取消，按原任务恢复并取得持久视频资产。覆盖旧 WL-05/06/07；不建设剪辑合成器、分布式调度平台，不自动重提未知付费任务，也不开放 Agent 工具。

下列旧仓库 `backend/app/` 来源仅为 2026-11-09 的迁移调查依据，不证明当前在线可用：

| 协议族与旧来源                                               | 目标差异                                                                                                          |
| ------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| Seedance/Vega：`services/video_gen/base.py`、`seedance.py`   | `/volc/api/v3/contents/generations/tasks`；文生、首尾帧、全能参考，音视频/水印参数按型号限制；认证素材联动属 W6。 |
| Kling/Vidu：`services/video_gen/kling.py`、`vidu.py`         | `/kling/v1/...`、`/vidu/ent/v2/...`；普通、主体参考、多镜头/多帧、数字人等仍支持操作逐项映射。                    |
| Veo/HappyHorse：`services/video_gen/veo.py`、`happyhorse.py` | Veo predictLongRunning/operation/受保护下载；HappyHorse 提交/查询、生成和编辑。                                   |

实施者从当前账户动态目录选择精确协议/操作代表，使用短时长、小规格和合成或已授权输入，保留全部目标差异。旧模型数不充当可用白名单，目录发现不等于对应操作已实现或已验。

## 2. 直接依赖与 C0 缺口

凭据、成员和模型身份直接沿[供应商规范](../../providers.md)，必要基线为已接受 `onelink-user-provider-catalog`（[成果入口](../onelink-integration/complete/report.md)）。任务/资产与安全恢复直接引用[共享候选设计](../onelink-image-generation/design.md)，实施前核对 W3 首个消费者实际交付的基础接口、固定代码及接受范围，不把完整图片 PRD 或其全部成果作为前置。

C0 核对本视频切片授权和真实预算（O1）、旧凭据与已提交任务查询/清理（O2）、单实例/轮询次数/总时限/并发/停机恢复（O4）、精确型号/模式清单（O5），按[共同决定](../onelink-image-generation/design.md#5-仍须收口的共同决定)收口。逐协议确认查询、幂等和取消：旧版只有 Seedance 有上游删除分支，其他协议不能据此宣称支持取消；不支持项明确返回限制。缺真实调用结果属于 C1，不将未来证据当规划前置。

## 3. C1 实施顺序

沿[统一生命周期](../../coordination.md#当前任务的生命周期)，在已有基础上扩展必要 submit/poll/materialize 与有界调度，再按清单实现请求、状态映射、结果和受保护下载，保存原供应商及查询上下文。W4/W5 的异步需求共用一个维护中的任务机制；若 W5 先提供相应步骤则直接核对复用，不要求先完成本页所有协议。

随后处理重启、轮换、禁用、unknown、取消竞态和原任务落库恢复。上游 ID 持久与本地 ACK 的故障窗口随实现测试；必要视频/调度规范、HTTP 与集成契约在对应切片 verify 前采纳并链接消费者。认证素材引用等待 W6 的 Active 校验和解析，普通视频切片可先独立交付。

## 4. 验收与接受

共同原 A1/A2/A5/A6/A7、批次原件和接受条件沿[共同验证约定](../onelink-image-generation/design.md#6-共同验证约定)，本页另要求：

- 每个协议族真实提交并取回可解码、可重新下载的视频；文生、首尾帧、主体参考、编辑、数字人、多镜头/多帧及其他已纳入模式按清单分别验证，不用一个生成结果代替全部模式。
- 故障覆盖提交前、上游已收未回 ID、ID 已得未提交、查询中断、下载失败、资产已存未收口及重启；断言收费 POST 次数、原查询身份和可恢复结果，下载/落库失败不重新生成。
- 提交前/中/后的取消、上游不支持取消、禁用/轮换和停止恢复均保留真实结果；无上游保证就保持 unknown/费用未知，新成功不覆盖旧失败。

目标无权/不可用/未验按共同规则明确处置；普通模式与待 W6 联动模式分别披露。仅完成切片就只接受该切片，相关模式清单全部收口并有证据后才声明对应完整视频能力；工具与生产部署不由此开放。
