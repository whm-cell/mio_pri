# 万联语音、音色、音乐与翻唱 PRD

状态：原 W5 的独立需求规划，尚未启动或接受。声音样本和外部资源授权仍须按本页收口。返回[任务资料与成果](../index.md)。

## 1. 结果与范围

覆盖旧 WL-08/09：同步/异步 TTS、分段情绪/适用字幕、音色查询/设计/复刻、音乐/歌词/翻唱预处理与生成；用户可查询音色、任务和持久音频资产。非目标为配音工作台 UI、平台音色市场、未授权真人声音和 Agent 工具。

旧仓库 `backend/app/services/tts.py`、`minimax_voice_runtime.py` 的 speech-* 使用 `/minimax/v1/t2a_v2`，还包括异步长配音、文件上传/取回及音色能力；`services/music_runtime.py`、`routers/music.py` 包括 `/minimax/v1/music_generation`、lyrics_generation 和 music_cover_preprocess。这些是迁移目标依据，不表示当前账号或所有旧型号可用；原生 MiniMax 路径和业务返回须独立适配，不以普通 chat 协议代替。

## 2. 直接依赖与 C0 缺口

本人凭据、动态目录/模型身份和有来源声明沿[供应商规范](../../providers.md)，必要基线为已接受 `onelink-user-provider-catalog`（[成果入口](../onelink-integration/complete/report.md)）；任务/资产直接引用[共享候选设计](../onelink-image-generation/design.md)，核对首个消费者实际提供的接口与代码，不默认读整份图片 PRD。

C0 收口本音频切片授权和批次预算（O1）、旧凭据与文件/音色关系（O2）、音频容量/处理环境/保留清理（O4）及精确模型/操作清单（O5）。O6 另确认合成或已获授权的复刻/翻唱样本、外部文件与音色创建/删除权限及资源保留；未授权样本不用于验证。音色和上游文件持久绑定 owner、providerConfigId、上游 ID/来源，同用户换 Key 不自动认领旧资源；上游账号身份和删除副作用未定只阻塞相关操作。

W5 可消费已核验的共同异步机制；若先于视频相应机制实施，就在本单元交付所需最小步骤，由 W4 复用同一维护实现，不复制调度，也不等待全部视频能力完成。必要 FFmpeg/分段环境只随真实消费者接入并明确超时、关闭和制品条件，不能预设本机工具已是部署契约。

## 3. C1 实施顺序

沿[统一生命周期](../../coordination.md#当前任务的生命周期)，先完成原生 MiniMax 适配和 HTTP 200 内业务错误检查，再处理文件上传/音色 owner；同步配音与解码后扩展异步长配音查询/取回、分段合成/字幕，最后按实际依赖接音乐、歌词及翻唱。每项保存任务、外部文件和音色来源，局部失败只恢复相应步骤，不重新收费复刻或生成。

缺当前用户配置不回退其他供应商或管理员 Key；音色查询、设计、复刻及外部文件清理分别表达副作用。音频/外部资源规范、HTTP 和集成契约随对应切片在 verify 前进入候选，不把原始音色 ID 变成跨用户通用资源。

## 4. 验收与接受

共同原 A1/A2/A5/A7、真实批次与接受条件沿[共同验证约定](../onelink-image-generation/design.md#6-共同验证约定)，原 A8 要求另逐项取证：

- 两种配音模型、异步长文、支持的情绪/字幕、音色设计/复刻、音乐、歌词、翻唱各有对应结果。实施者按当前账户和操作选精确代表，不用一个音频文件代替全部能力，也不用旧模型数充当可用名单。
- 实际音频可解码，时长/格式与资产可读；歌词按文本操作断言。覆盖 hex/URL 响应、HTTP 200 内业务失败、分段部分失败和临时文件过期，不能仅验 HTTP 200。
- 跨用户音色/文件、换 Key、轮询中断、取消、复刻/生成成功后的落库失败及资源异常/清理分别验证，断言不重复收费执行和可恢复身份。

无权限/不支持项如实登记，完整音频接受须覆盖本页全部目标或获明确处置并披露；局部切片只接受自身范围，恢复、安全和审查随切片交付。
